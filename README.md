# Labirynt Mitów – wersja na GitHub Pages

Ta gałąź zawiera tylko opublikowaną grę: `index.html`, `css/` i `src/` skopiowane bez zmian z gałęzi `main`.
Kod, testy i opis gry są na gałęzi `main`.

- Gra jest stroną projektu, więc działa pod podścieżką (`/mity/`); wszystkie odwołania w `index.html` są względne.
- `.nojekyll` wyłącza Jekylla, dzięki czemu GitHub Pages podaje pliki bez przetwarzania.
