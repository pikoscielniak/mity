# Labirynt Mitów – wersja na GitHub Pages

Ta gałąź zawiera tylko opublikowaną grę: `index.html` to jednoplikowa wersja zbudowana z gałęzi `main`
poleceniem `npm run build` (plik `dist/labirynt-mitow.html`). Kod źródłowy, testy i opis gry są na gałęzi `main`.

`.nojekyll` wyłącza przetwarzanie strony przez Jekylla, więc GitHub Pages podaje plik bez zmian.
